1. Пояснення для кожного системного виклику:
    - open: відкриває або ствроює файл.
        - аргументи:
            - pathname: шлях до файла.
            - flags: різноманітні прапорці для режиму доступу та поведінки.
            - mode: права доступу у вісімковій формі.
        - повертає:
            - при успіху: файловий дескриптор.
            - при помилці: -1.
    - write: записує дані з буфера пам'яті у відкритий файл.
        - аргументи:
            - fd: файловий дескриптор.
            - buf: вказівник на область пам'яті, з якої зчитуються дані.
            - count: кількість байтів, яку потрібно записати.
        - повертає:
            - при успіху: кількість фактично записаних байтів.
            - при помилці: -1.
    - read: зчитує дані з файла в буфері пам'яті.
        - аргументи:
            - fd: файловий дескриптор.
            - buf: вказівник на область пам'яті, куди будуть збережені прочитані байти.
            - count: максимальна кількість байтів для зчитування.
        - повертає:
            - при успіху: кількість фактично прочитаних байтів.
            - при помилці: -1.
    - lseek: змінює курсора у файловому дескрипторі.
        - аргументи:
            - fd: файловий дескриптор.
            - offset: велечина зміщення в байтах.
            - whence: базова точка відліку для зміщення.
        - повертає:
            - при успіху: нову абсолютну позицію курсора в байтах.
            - при помилці: -1.
    - close: закриває файловий дескриптор.
        - аргументи:
            - fd: файловий дескриптор.
        - повертає:
            - при успіху: 0.
            - при помилц: -1.
